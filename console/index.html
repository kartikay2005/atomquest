    Using the console

    1. Pick a scenario. Open "Scenario", choose a month (May is hot and dry, August is humid), a start date and how many nights, then Apply and restart.
    2. Control time. ▶/❚❚ (or the space bar) plays and pauses; 600× means one simulated hour passes in six seconds. Click the timeline, or the 21:00 / Midnight / 03:00 / 06:00 buttons, to jump.
    3. Compare the two rooms. Left is a normal room, right is the same room with Duet. Same weather, same person, same random luck. The top row shows tonight's AC energy and comfort.
    4. Try to break it. Inject a fault or press the user's remote, then read the firmware log: Duet should step back, never fight the user, and never break a safety rule.
    5. See the connections. The "How it connects" tab draws the whole loop with live values.

    Words used here

    PMVPredicted Mean Vote: ASHRAE 55's comfort score. 0 is neutral, +1 slightly warm, −1 slightly cool. Between −0.5 and +0.5 counts as comfortable.
    SetpointThe temperature the AC is told to hold. Every degree higher saves roughly a tenth of the AC's energy.
    Safety governorThe one function every AC command must pass: 24–28 °C, 1 °C per 20 min, 3 changes an hour, no raise above 60% humidity, nothing if the sensor is faulty, and the user's remote always wins.
    SILSoftware in the loop: the firmware's own C++ code, compiled for this computer instead of the chip, driven by a simulated room.
    SeedFixes the random luck (weather wobble, arrival time, sensor noise). Same seed, same run: that is how the two rooms get identical conditions.
